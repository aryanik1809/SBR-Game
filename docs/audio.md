# Audio

All sound in the game is generated by code, no samples: `python3 tools/make_audio.py` writes
`assets/audio/*.ogg` (37 files, ~2.5 MB) plus `manifest.json`. Needs `numpy scipy soundfile` and `ffmpeg`.

## Music: an original theme "inspired by" Steel Ball Run

120 BPM, E minor with a B7 dominant and Phrygian colour. A galloping long-short-short rhythm runs
through the guitar, bass and drums; trumpets carry the heroic melody, a choir pad and timpani give the
JoJo-style bombast, and a snare roll plus riser builds into the final chorus (melody doubled in thirds,
octave-down brass).

| Track | Length | Use |
| --- | --- | --- |
| `theme_title` | 40 s, loops | Title screen: drum-roll intro, fanfare hit, riff, then the main melody |
| `theme_race` | 56 s, loops | Gameplay: riff, melody, breakdown, big finale |
| `stinger_start` | 6 s | The "pose" hit when you press start |

## Sound effects

Hoofbeats (dirt thud and softer walking variants, 4 each), gallop burst, 3 whinnies, nicker, snorts,
breathing, saddle creaks, tack jingles, whip crack, boost whoosh, skid, landing thud, jump, panting,
stamina-ready chime, UI click/hover, a distant vulture, and looping ambiences: ominous drone
(title), desert wind, and a crackling camp fire (3D, placed at the camp_fire landmark).

## Getting it to play in Roblox

Roblox can only play audio that has been uploaded to it, so the `.ogg` files are not used directly.
Until they're uploaded every sound in `src/shared/AudioIds.luau` has `id = 0` and the game is just silent
(it prints how many sounds are missing on start).

**Option A, script it** (needs an ID-verified account and an Open Cloud API key with `asset:read` and
`asset:write`, from create.roblox.com > Credentials):

```
python3 tools/upload_audio.py --upload --api-key YOUR_KEY --user-id YOUR_USER_ID
# or --group-id for a group; add --only theme_title theme_race to do a few first
```

It writes the returned asset IDs into `src/shared/AudioIds.luau`, saving after each upload so an
interrupted run keeps its progress. Commit that file. Audio goes through moderation, so a freshly
uploaded sound may stay silent for a few minutes.

**Option B, by hand**: Studio > Asset Manager > Bulk Import, import the files in `assets/audio/`, then
paste each ID into `AudioIds.luau` (`name = { id = 123456, ... }`).

The uploader was written against the documented Open Cloud Assets API but has not been run against a
real account, so check the first upload's output.

## Mixing

`Config.Audio` sets the Music / Sfx / Ambience group volumes. Per-sound volumes live in the manifest
(`tools/make_audio.py`, `META`). Press **M** in game to mute the music.
